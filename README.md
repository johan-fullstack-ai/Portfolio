# Johan Granvinge’s Portfolio

A modern, responsive personal portfolio built with **React**, featuring clean UI patterns, smooth navigation, Framer Motion animations, and a structured component-based architecture.  

This site showcases Johan’s professional profile, CV, and selected development projects.

---

## 📌 Features

- **Four main pages:** Home, About, Projects, CV  
- **Embedded CV page** using an external URL  
- **Responsive layout** with accessible navigation and keyboard‑friendly interactions  
- **Framer Motion bubble animation** behind the logo  
- **Smooth scroll** to footer contact section and to top if navbar is used
- **Project cards** with hover effects, demo links, and GitHub links  
- **Lazy‑loaded images** (except hero image)  
- **ARIA‑friendly** markup and focus-visible styles  
- **Deployed on GitHub Pages**
